# Task Manager

A full-stack Task Manager web application built with **React (Vite)** for the frontend and **Node.js/Express** for the backend.  
This app allows users to create, view, update, and delete tasks in a simple and intuitive interface.

---

## 🛠 Tech Stack

- **Frontend:** React, Vite, JavaScript, HTML, CSS  
- **Backend:** Node.js, Express, REST API  
- **Database:** MongoDB
